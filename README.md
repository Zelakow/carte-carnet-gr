# Carte Carnet GR

Page de carte IGN (Plan IGN, carte classique, photos aériennes) pour l'application Carnet GR.
Le parcours à afficher arrive dans l'adresse, après le `#` : rien n'est enregistré ni envoyé à un serveur, à part les fonds de carte demandés à l'IGN (Géoplateforme).

Adresse : https://zelakow.github.io/carte-carnet-gr/
